# Home page

Scope: `src/app/page.tsx`, the page each self-hosted instance serves at `/` (not indexed). Visitor mode: Persuade.

Audience and job: developers who find the project (on GitHub or on someone's instance) and decide whether to install it; operators of an instance looking for the admin panel. Action: install it (clone + compose) or open the admin. Proof: real features, the real quickstart commands, the real API request; no invented users, stars or benchmarks. The "Not tax advice" warning must be present.

Memorable moment: the whole quickstart drawn as one red metro line, six stations from clone to the first live invoice.

## Direction contract

THESIS: The home page is one metro line: the journey from git clone to the first live invoice, each station a real step with its real command. It refuses the SaaS split hero with a badge row and three feature cards.

OWN-WORLD: Milano Moderna, as in the admin brief: white ground, signal red, near-black ink, Inter Tight extra-bold display, 2px rules, square corners, black command blocks in JetBrains Mono. Green marks the final Live station.

STORY: The visitor reads the name and one sentence, sees the six stations and understands it is self-hosted and quick to set up, scrolls to why it exists, what it handles (customer categories, stamp duty, dry run, idempotency), the API request and response, and the tax-advice limit, then clones it or opens the admin.

FIRST VIEWPORT: Top bar: product name left, links (Why, API, GitHub, Admin) right. Huge two-tone "fic-invoicing" display (red second half) with one lead sentence below; GitHub and Open admin actions top right of the hero. Below, full width, the red line with six stations: Clone, Start, Create a tenant, Connect, Dry run, Live, each with its command or one-line action.
